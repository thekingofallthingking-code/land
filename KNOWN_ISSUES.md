# Known issues and verification gaps

- The available host is Linux. The Windows batch scripts, OS mouse capture, OpenAL playback and GPU performance on the target PC need a Windows check.
- The city uses fixed parked vehicles in Section 1. Pedestrians, moving traffic, gunplay and police pursuit are later-section work.
- Offscreen Mesa llvmpipe measurements use CPU rendering and cannot establish the 1080p laptop frame-rate target.
